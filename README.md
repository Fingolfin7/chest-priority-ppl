# Rolling PPL

A phone-first, chest-prioritized rolling Push/Pull/Legs workout reference. The sequence continues across five weekdays instead of resetting every Monday, so missed sessions never require rescheduling the week.

## Features

- Complete three-week rolling schedule
- Device-local “next workout” tracker
- Gym-readable exercise cards with sets, reps, rest, cues, original movement diagrams, and external technique references
- Warm-up, progression, rest, and safety guidance
- Responsive static build for GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Build the production site with `npm run build`. Output is written to `dist/`.

This project provides general workout organization and technique reminders, not medical care.
